- **修复公考模块交互 bug**：初次生成的 JS 有 2 个语法错误导致点击无反应——
  1. `gkRenderHabit` 函数缺少 closing `}`（修复时误删）；
  2. onclick 处理器引号转义错误：`\'` 在 Python f-string 中只产生 `'`，导致 JS 单引号字符串提前闭合。
     正确写法是在 Python 源中用 `\\'` 输出 `\'`（JS 转义单引号）。已用 `node --check` 验证 JS 语法通过，并模拟确认 `gkToggleHabit('count','0',this)` 可正常调用。
- 教训：在 `workbench.py` 的 f-string 三重引号内嵌 JS 时，JS 所需的转义引号必须写成 `\\'`（Python 层）才能输出 `\'`（JS 层）。
